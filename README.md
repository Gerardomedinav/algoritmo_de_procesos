
# Emulador de Algoritmos de Planificación de Procesos

Este proyecto es una herramienta educativa desarrollada con HTML, CSS y JavaScript que permite simular y visualizar cómo los algoritmos de planificación de procesos gestionan la ejecución de tareas en una CPU.

## Demo en línea

https://algoritmo-de-procesos.vercel.app/

## Funcionalidades principales

- Emulación de algoritmos como FCFS (First Come First Served), SJN (Shortest Job Next) y Round Robin (RR).
- Visualización de la ejecución de procesos con gráficos de Gantt y diagramas dinámicos.
- Comparación de métricas como tiempos de espera, retorno y ejecución.
- Interfaz gráfica intuitiva que permite ingresar datos personalizados.
- Completamente responsivo y adaptable a distintos tamaños de pantalla.

## Cómo usar el proyecto

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Gerardomedinav/algoritmo_de_procesos.git
   ```
2. Ingresar a la carpeta del proyecto:
   ```bash
   cd algoritmo_de_procesos
   ```
3. Abrir el archivo `index.html` en tu navegador o utilizar Live Server.

No requiere instalación adicional de dependencias.
